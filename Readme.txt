النسخة النهائية – سوق أرباب المعاصر
===================================
رابط المجموعة:
https://chat.whatsapp.com/DdPqC7qvnZ264Y5mGvVvts

الخصائص:
- أربعة مسارات مستقلة: بيع/طلب زيت الزيتون + بيع/طلب المعدات والتجهيزات.
- قوالب نشر مختصرة ومختلفة حسب نوع العملية.
- رقم عملية تلقائي مبني على وقت إنشاء الإعلان.
- إدراج المنتج والكمية والثمن/الميزانية والمنطقة والوحدة والصفة.
- شرط ONSSA مدمج في صفحات زيت الزيتون.
- رفع عدة صور وفيديوهات وملفات مع معاينة.
- موافقة إلزامية على القانون الداخلي.
- نشر مباشر دون انتظار موافقة المشرف.
- للمشرف حق حذف المنشور المخالف للقانون الداخلي.
- مشاركة النص والمرفقات عبر Web Share API عند دعم الجهاز.
- بديل «نسخ وفتح المجموعة» للهواتف والمتصفحات التي لا تدعم المشاركة بالملفات.

ملاحظة: رابط دعوة مجموعة واتساب لا يسمح لصفحة HTML بإدخال منشور تلقائيًا داخل المجموعة دون تفاعل المستخدم. لذلك زر النشر يشارك الإعلان من الهاتف أو يفتح المجموعة، ويظل الضغط النهائي على «إرسال» بيد صاحب الإعلان.
