# سوق أرباب المعاصر – واجهة البيع والشراء

الملفات:
- index.html: الصفحة الرئيسية
- oil-sell.html: بيع زيت الزيتون
- oil-buy.html: طلب شراء زيت الزيتون
- equipment-sell.html: بيع المعدات والتجهيزات والمستلزمات
- equipment-buy.html: طلب شراء المعدات والتجهيزات والمستلزمات
- logo.png: شعار المجموعة

قبل النشر:
1. افتح الملفات واستبدل GROUP_LINK في الصفحات برابط مجموعة واتساب الحقيقي.
2. يمكن تعديل ADMIN_NUMBER لاحقًا إذا أردت إضافة مسار إرسال للمشرف.
3. رفع الصور/الفيديو/الملفات يعمل داخل الصفحة. وفي الهواتف التي تدعم Web Share API يمكن مشاركة النص والملفات إلى واتساب من نافذة المشاركة. لا يمكن لصفحة HTML وحدها نشر الرسالة تلقائيًا داخل مجموعة واتساب دون تفاعل المستخدم أو تكامل رسمي.
